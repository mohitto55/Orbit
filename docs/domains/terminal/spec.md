# 터미널 기능 명세

하위 도메인의 규칙을 조정해 이루는 사용자 기능과 수용 기준. 기능마다 쓰는 규칙을 참조한다.

| ID | 기능 | 목적 | 수용 기준 | 상태 |
|---|---|---|---|---|
| TE-F01 | 터미널 작업 | 프로젝트별 작업 세션을 다시 열어 이어서 작업한다 | AC1: 선택한 프로젝트의 폴더에서 터미널 세션이 시작된다<br>AC2: Codex·Claude 실행 및 재개 명령을 설정 화면에서 변경할 수 있다<br>AC3: Orbit을 종료하면 실행 중인 작업은 중단되지만, 다음에 같은 프로젝트를 선택하면 기존 CLI 세션 ID로 자동 재접속한다. 셸 프롬프트나 새 세션만 띄우는 것으로 복원을 완료하지 않는다<br>AC4: 터미널 탭 이름을 수정할 수 있고 재시작 후에도 유지된다<br>AC5: 프로젝트별로 열어 둔 탭의 순서·이름·선택 상태와 최근 터미널 화면을 복원한다. 사용자가 닫은 탭은 다시 열지 않는다<br>AC6: 앱 시작 시 프로젝트 폴더 선택 화면을 보여 준다. 마지막 프로젝트로 자동 진입하지 않으며, 사용자가 프로젝트를 선택한 뒤 해당 프로젝트의 세션을 복원한다<br>AC7: 터미널 복원에 대화 본문 읽기나 가져오기가 필요하지 않다. ‘저장된 대화’ 버튼이나 별도의 대화 선택 없이 복원된다<br>AC8: 전용 실행 버튼뿐 아니라 일반 터미널에서 직접 실행한 Codex·Claude도 복원 대상이다. CLI에서 기존 대화를 선택해 재개했다면 실제 선택한 세션으로 돌아온다<br>AC9: CLI 입력창에서 Ctrl+Enter 또는 Shift+Enter를 누르면 전송하지 않고 줄바꿈한다. 두 줄을 입력해 전송하면 줄바꿈이 보존되며, 키 이벤트 중복이나 한글 조합으로 줄바꿈이 중복되지 않는다 | 초안 |

## 규칙

- 세션 복원은 사용자가 선택한 프로젝트에만 적용한다.
- 대화 내용은 각 CLI가 관리한다. Orbit은 복원에 필요한 탭 상태와 세션 식별 정보를 저장한다.
- 앱 시작, 프로젝트 선택, CLI 재접속, 여러 줄 입력을 실제 사용 순서로 검증한다.
