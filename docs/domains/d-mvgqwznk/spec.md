## 규칙

- `세션 불러오기` 목록은 Claude Code·Codex에 저장된 세션 이름을 우선 표시한다. 이름이 없을 때만 첫 메시지를 사용하며, 원본 세션 이름이나 대화 기록은 변경하지 않는다.
- 선택한 세션이 Orbit에서 이미 실행 중이면 같은 종류·세션 ID의 터미널 탭을 재사용한다. 탭 이름·출력·그룹을 유지하며, 실행 중인 탭이 없을 때만 새 탭을 연다. 같은 터미널을 다른 작업 노드가 사용 중이면 중복 전송하지 않고 해당 작업이 끝난 뒤 다시 실행하도록 안내한다.
- 기존 탭을 재사용할 때는 화면 출력이 멈추기를 기다리지 않고 프롬프트를 바로 보낸다. 새 탭은 입력 준비를 기다리며, 준비 중에도 다른 노드가 그 터미널에 중복 입력할 수 없다.
- 함수 변수 타입은 텍스트와 텍스트 리스트다. 연결된 입력은 연결 값을 사용하고, 연결하지 않은 입력은 호출 노드에 적은 기본값을 사용한다. 리스트 기본값은 한 줄에 한 항목이다.
- 함수 Input은 내부로 인자를 내보내고, Output은 반환값을 받는다. 실행 선은 Input에서 시작해 Output으로 돌아와야 한다. 경계 노드는 삭제할 수 없고, 변수는 추가·삭제할 수 있다.
- 함수의 변수마다 이름과 별개인 고정 ID가 있어 이름을 바꿔도 선은 유지된다. 타입 불일치, 없는 변수, 중복 입력 연결, 빠진 반환값, 함수 순환 호출은 실행 전에 알린다.
- 함수는 중첩 호출할 수 있으며 각 호출의 인자와 반환값을 구분한다. 셸 출력을 반환받는 노드는 실행 선으로 그 함수 뒤에 있어야 한다.
- 예전 템플릿은 Input·Output을 덧붙여 읽는다. 기존 실행 흐름과 `{{입력}}`, 직접 입력 뒤에 연결 데이터를 붙이는 동작을 유지한다.
