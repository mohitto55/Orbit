# 관계도

## 역할

모든 도메인의 대상을 노드로, 그 사이 관계를 링크로 관리하고 그래프로 보여준다. Obsidian처럼 링크를 가볍게 걸고 탐색할 수 있게 한다.

## 용어

이 도메인(바운디드 컨텍스트) 안에서의 뜻이다. 같은 단어도 다른 도메인에서는 뜻이 다를 수 있다.

| 용어 | 뜻 | 비고 |
|---|---|---|
| 노드 | md 문서 하나 |  |
| 링크 | 노드 간 관계. frontmatter와 본문 `[[ ]]`에서 읽는다 |  |
| 링크 종류 | `상위` / `소속` / `기준` / `참조` / `의존` / `관련` / `대응` / `근거` | `관련`은 종류 없는 가벼운 링크 |
| 미정의 노드 | 링크는 있지만 문서가 없는 노드 |  |
| 백링크 | 나를 가리키는 노드 목록 |  |
| 이름 링크 해석 | `[[이름]]`을 형제 → 조상 경로 → 전체 순으로 찾아 id로 확정하는 것 |  |
| 인덱스 | md에서 만든 노드·링크 캐시. 지워도 다시 만들 수 있다 |  |

## 하지 않는 것

- 각 노드의 내용과 규칙 (각 도메인이 책임)

## 다른 도메인과의 관계

| 방향 | 대상 | 내용 |
|---|---|---|
| 수신 | 프로젝트 | 파일 변경 알림 |
| 제공 | 모든 도메인 | 백링크, 이름 링크 해석, 하위·의존 도메인 조회 |
