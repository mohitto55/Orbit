# 프로젝트 기능 명세

하나의 프로젝트와 그 저장소를 대표한다.

| ID | 기능 | 목적 | 수용 기준 | 상태 |
|---|---|---|---|---|
| WS-F01 | 프로젝트 만들기 | 로컬 폴더를 Orbit 프로젝트로 만든다 | AC1: 폴더를 고르면 데이터 폴더와 하위 폴더가 생성된다<br>AC2: `project.md`에 프로젝트 이름과 생성일이 기록된다<br>AC3: git 저장소가 아니어도 경고 후 생성할 수 있다<br>AC4: 데이터 폴더의 인덱스 캐시가 `.gitignore`에 추가된다 | 초안 |
| WS-F02 | 프로젝트 열기 | 기존 프로젝트를 이어서 작업한다 | AC1: 데이터 폴더가 있는 폴더를 고르면 프로젝트로 열린다<br>AC2: 인덱스가 없거나 md보다 오래됐으면 다시 만든다<br>AC3: 다른 PC에서 clone한 저장소도 같은 상태로 열린다<br>AC4: 이름을 바꾸기 전 `.girsktop/` 프로젝트도 그대로 열린다<br>AC5: 앱을 시작하면 프로젝트 선택 화면이 먼저 보인다. 마지막 프로젝트를 자동으로 열지 않는다<br>AC6: 사용자가 프로젝트를 고른 뒤 해당 프로젝트에 저장된 터미널 탭과 CLI 세션을 자동 복원한다. 다른 프로젝트의 세션은 섞이지 않는다<br>AC7: 전체 소스 검사·변경 검토 복원을 기다리지 않고 프로젝트 화면을 연다. 처리된 변경은 재검사하지 않으며 빌드 산출물·캐시의 테스트는 제외한다. 복원 오류는 별도 알림으로 전달하고 프로젝트를 닫거나 전환하면 진행 중인 검사를 취소한다 | 초안 |
| WS-F03 | 최근 프로젝트 전환 | 여러 프로젝트를 빠르게 오간다 | AC1: 최근 연 프로젝트가 최신순으로 표시된다<br>AC2: 목록에서 고르면 해당 프로젝트로 전환된다 | 초안 |
| WS-F04 | 프로젝트 설정 | 프로젝트별 동작을 조정한다 | AC1: 대화 검토 주기, 리마인드 시각, GitHub 저장소, 테스트 명령을 설정할 수 있다<br>AC2: 설정은 `project.md` frontmatter에 저장된다 | 초안 |
| WS-F05 | 외부 변경 감지 | 앱 밖에서 바뀐 문서를 바로 반영한다 | AC1: 에디터·git pull·에이전트가 md 파일을 바꾸면 앱 재시작 없이 반영된다<br>AC2: 에이전트가 `inbox/`에 만든 파일이 Inbox 목록에 나타난다 | 초안 |
| WS-F06 | 마크다운 원문 편집 | 모든 문서 본문을 md 파일처럼 직접 고친다 | AC1: 할 일·도메인·설계·지식·수정안의 공통 편집기는 마크다운 원문으로 열린다. Enter는 한 줄을 바꾸고 HTML 단락이나 목록으로 자동 변환하지 않는다<br>AC2: 빈 줄·제목·목록·표·코드·HTML·위키링크의 원문을 편집하며 붙여넣기·선택·한글 조합·실행 취소는 텍스트 입력처럼 동작한다<br>AC3: 미리보기는 읽기 전용이다. 모드 전환은 원문·커서·편집 기록을 유지하고 저장은 각 화면의 저장 동작으로 수행한다 | 초안 |

## 규칙

- 프로젝트 하나 = 데이터 폴더 하나.
- 도메인 폴더는 도메인 단위로 문서를 묶을 뿐, 계층을 뜻하지 않는다 (중첩 없음, 상위는 `parent`로 표기).
