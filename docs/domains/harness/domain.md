# 에이전트 지침

## 역할

프로젝트 문서를 바탕으로 Claude Code / Codex용 작업 환경 파일을 만들고, 원본이 바뀌면 다시 만들 때가 됐음을 알린다.

## 용어

이 도메인(바운디드 컨텍스트) 안에서의 뜻이다. 같은 단어도 다른 도메인에서는 뜻이 다를 수 있다.

| 용어 | 뜻 | 비고 |
|---|---|---|
| 하네스 | 에이전트가 프로젝트 문서 체계를 따르게 하는 작업 환경 파일 묶음 |  |
| 프로필 | 대상 에이전트(Claude Code / Codex)별 생성 설정 |  |
| 생성 결과물 | `CLAUDE.md`, `AGENTS.md`, skill, slash command 등 |  |
| 관리 영역 | 생성 파일에서 표식 사이 구간. 앱은 여기만 고친다 |  |
| 생성 기준 | 생성할 때 쓴 원본 문서와 버전 목록 |  |
| 낡음 | 생성 기준 이후 원본이 바뀐 상태 (도메인 작은 변경 제외) |  |

## 하지 않는 것

- 에이전트 실행
