# 지식 기능 명세

결정 사항, 용어, 컨벤션, 교훈 같은 프로젝트 지식을 쌓는다.

| ID | 기능 | 목적 | 수용 기준 | 상태 |
|---|---|---|---|---|
| KN-F01 | 지식 작성 | 문서에 안 들어가는 지식을 남긴다 | AC1: 종류(결정 / 용어 / 컨벤션 / 교훈 / 주의), 제목, 본문, 근거 출처(선택)로 저장된다<br>AC2: 결정 종류는 배경 / 결정 / 대안 / 결과 템플릿으로 시작한다 | 초안 |
| KN-F02 | 작업 대화 초안 받기 | 대화 속 지식을 놓치지 않는다 | AC1: 작업 대화의 `지식` 표시가 발췌를 근거로 붙인 초안이 된다<br>AC2: 사람이 저장하기 전까지 초안 상태다 | 초안 |
| KN-F04 | 폐기와 대체 | 뒤집힌 결정을 추적한다 | AC1: 상태는 유효 / 폐기됨이다<br>AC2: 새 결정으로 대체하면 이전 항목이 폐기되고 서로 연결된다 | 초안 |
| KN-F05 | 목록·검색 | 필요한 지식을 찾는다 | AC1: 종류별 목록과 제목·본문 검색이 된다 | 초안 |

## 규칙

- 도메인 규칙은 지식이 아니라 도메인에 넣는다.
- `용어` 종류는 **프로젝트 전반 용어**만 담는다. 한 도메인 안에서만 유효한 용어는 그 도메인의 `domain.md` 용어 섹션(Term 개념)에 둔다.
- 기술 구조 결정 중 여러 기능에 걸친 것은 시스템 공통 설계에 넣고, 지식에는 결정 경위(왜)만 남긴다.
