# 관계도 기능 명세

모든 문서를 노드로, 문서 사이 관계를 링크로 관리하고 그래프로 보여준다.

| ID | 기능 | 목적 | 수용 기준 | 상태 |
|---|---|---|---|---|
| KG-F01 | 노드·링크 읽기 | md 파일에서 관계를 뽑는다 | AC1: 데이터 폴더의 md 파일마다 노드가 생긴다<br>AC2: frontmatter의 관계 필드와 본문 `[[ ]]`에서 링크가 생긴다<br>AC3: 인덱스를 지우고 다시 열면 같은 그래프가 만들어진다 | 초안 |
| KG-F02 | 링크 종류 | 관계의 의미를 구분한다 | AC1: 링크 종류는 상위 / 소속 / 기준 / 참조 / 의존 / 관련 / 대응 / 근거다<br>AC2: 본문 `[[ ]]`는 기본으로 `관련`이 되고, 나중에 다른 종류로 바꿀 수 있다 | 초안 |
| KG-F03 | 이름 링크 해석 | 이름이 겹쳐도 올바른 노드를 가리킨다 | AC1: `[[이름]]`은 같은 상위의 형제 → 조상 경로 → 전체 순으로 찾는다<br>AC2: 후보가 여럿이면 사람이 고르고, 저장 시 `[[id]]`로 확정된다<br>AC3: `[[상위/이름]]` 경로 표기가 된다 | 초안 |
| KG-F04 | 미정의 노드 | 아직 없는 개념을 드러낸다 | AC1: 없는 노드를 가리키는 링크는 흐리게 표시된다<br>AC2: 클릭하면 그 이름으로 문서를 만들 수 있다 | 초안 |
| KG-F05 | 백링크 | 나를 참조하는 문서를 본다 | AC1: 모든 문서 상세 화면에 백링크 목록이 표시된다 | 초안 |
| KG-F06 | 그래프 보기 | 구조를 한눈에 본다 | AC1: 전체 / 로컬(N단계) / 계층(상위 링크만) 보기가 있다<br>AC2: 노드 종류, 링크 종류, 도메인 유형으로 필터할 수 있다 | 초안 |
| KG-F07 | 상태 표시 | 문제 있는 곳을 그래프에서 찾는다 | AC1: 낡은 문서와 확인 대기 문서가 강조된다<br>AC2: 검증 실패·테스트 없음 기능이 강조된다 | 초안 |

## 규칙

- md 파일이 원본이고 인덱스는 캐시다.
- 링크는 `id`로 저장한다. 파일을 옮기거나 제목을 바꿔도 깨지지 않는다.
- 그래프는 관계를 보여줄 뿐 다른 문서를 바꾸지 않는다.

## 미결정 사항

- 사용자 정의 링크 종류 허용 여부
