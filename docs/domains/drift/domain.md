# Drift

> 해결 문제: P3

## 역할

주기적으로 사람에게 도메인 검토를 요청하고, 최근 작업 대화와 현재 도메인 모델을 나란히 보여준다. 사람이 수정하기로 하면 그 결정을 도메인 변경과 Task로 넘긴다.

## 용어

이 도메인(바운디드 컨텍스트) 안에서의 뜻이다. 같은 단어도 다른 도메인에서는 뜻이 다를 수 있다.

| 용어 | 뜻 | 비고 |
|---|---|---|
| 세션 (WorkSession) | Claude Code / Codex 대화 하나 |  |
| 검토 회차 (DriftCheck) | 검토 한 번. 대상 기간, 본 세션, 결과를 기록 |  |
| 검토 주기 | 검토 요청 알림 간격. 프로젝트 설정 |  |
| 표시 (Mark) | 사람이 대화 일부에 남기는 판단: `도메인 반영` / `할 일` / `지식` | 앱은 표시를 만들지 않는다 |
| 발췌 | 표시한 대화 부분. 세션 원본 대신 이것만 저장 |  |
| 검토됨 | 한 회차에서 이미 본 세션. 다음 회차에서 제외 |  |

## 하지 않는 것

- 차이를 스스로 판단하거나 도메인을 직접 수정

## 다른 도메인과의 관계

| 방향 | 대상 | 내용 |
|---|---|---|
| 수신 | Integration | 작업 대화 |
| 요청 | Domain Modeling | 도메인 변경 요청 |
| 요청 | Task · Knowledge | 할 일·지식 초안 |
