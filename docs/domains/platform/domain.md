# 앱 기반

## 역할

앱이 동작하는 환경을 제공한다. 화면 구성과 이동, 알림, 어디서나 쓰는 할 일 추가 단축키, 자동 업데이트를 맡는다.

## 용어

이 도메인(바운디드 컨텍스트) 안에서의 뜻이다. 같은 단어도 다른 도메인에서는 뜻이 다를 수 있다.

| 용어 | 뜻 | 비고 |
|---|---|---|
| 화면 | 사이드바 메뉴 하나에 대응하는 작업 공간 |  |
| 배지 | 처리할 일이 있는 화면 옆에 붙는 개수 표시 |  |
| 알림 | 운영체제 알림. 종류마다 하루 한 번만 보낸다 |  |
| 할 일 추가 단축키 | 앱이 뒤에 있어도 한 줄 기록 창을 여는 전역 단축키 (`Ctrl+Shift+Space`) |  |
| 자동 업데이트 | 설치판이 새 버전을 확인하고 내려받는 것 |  |

## 하지 않는 것

- 업무 판단
- 문서 내용 관리
