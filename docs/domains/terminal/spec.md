# 터미널 기능 명세

하위 도메인의 규칙을 조정해 이루는 사용자 기능과 수용 기준. 기능마다 쓰는 규칙을 참조한다.

| ID | 기능 | 목적 | 수용 기준 | 상태 |
|---|---|---|---|---|
| TE-F01 | 터미널 작업 | 프로젝트별 작업 세션을 다시 열어 이어서 작업한다 | AC1: 선택한 프로젝트의 폴더에서 터미널 세션이 시작된다<br>AC2: Codex·Claude 실행 및 재개 명령을 설정 화면에서 변경할 수 있다<br>AC3: Orbit을 종료하면 실행 중인 작업은 중단되지만, 다음에 같은 프로젝트를 선택하면 기존 CLI 세션 ID로 자동 재접속한다. 셸 프롬프트나 새 세션만 띄우는 것으로 복원을 완료하지 않는다<br>AC4: 터미널 탭 이름을 수정하고 저장할 수 있다. 사용자가 바꾸기 전까지 생성 시 정한 이름이나 저장한 이름을 유지한다<br>AC5: 프로젝트별로 열어 둔 탭의 순서·이름·선택 상태와 최근 터미널 화면을 복원한다. 사용자가 닫은 탭은 다시 열지 않는다<br>AC6: 앱 시작 시 프로젝트 폴더 선택 화면을 보여 준다. 마지막 프로젝트로 자동 진입하지 않으며, 사용자가 프로젝트를 선택한 뒤 해당 프로젝트의 세션을 복원한다<br>AC7: 터미널 복원에 대화 본문 가져오기가 필요하지 않다. ‘저장된 대화’ 버튼이나 별도의 대화 선택 없이 복원된다<br>AC8: 전용 실행 버튼뿐 아니라 일반 터미널에서 직접 실행한 Codex·Claude도 복원 대상이다. CLI에서 기존 대화를 선택해 재개했다면 실제 선택한 세션으로 돌아온다<br>AC9: CLI 입력창에서 Ctrl+Enter 또는 Shift+Enter를 누르면 전송하지 않고 줄바꿈한다. 두 줄을 입력해 전송하면 줄바꿈이 보존되며, 키 이벤트 중복이나 한글 조합으로 줄바꿈이 중복되지 않는다<br>AC10: AI가 세션 이름을 바꾸거나, 앱을 재시작·재연결하거나, CLI에서 다른 세션을 선택해도 터미널 탭 이름을 변경하지 않는다. 실제 세션 이름은 작업 그래프의 세션 불러오기 목록에 표시하며, CLI의 원본 이름과 대화 기록은 변경하지 않는다<br>AC11: 많은 탭을 복원하는 동안 프로젝트 화면이 응답한다. 터미널 화면은 처음 선택할 때 준비하고 그동안의 출력은 최근 20만 자까지 보관한다. 32MB 이상의 정상 저장 파일도 복원하며, 복원 도중 닫거나 전환해도 원본 저장 파일을 덮어쓰지 않는다 | 초안 |
| TE-F02 | 터미널 그룹 | 작업별로 탭을 묶어 보고 실행 중인 세션을 유지한 채 정리한다 | AC1: 그룹을 만들고 각 그룹 옆 이름 변경 버튼으로 이름을 바꿀 수 있다. 선택하지 않은 그룹의 이름도 변경할 수 있으며 빈 이름이나 중복 이름은 허용하지 않는다<br>AC2: 탭을 그룹에 끌어 놓거나 선택 목록으로 이동할 수 있다. 이동과 그룹 전환은 프로세스를 다시 실행하거나 출력을 초기화하지 않는다<br>AC3: 전체·미분류·지정한 그룹의 탭만 볼 수 있다. 그룹 안에서 연 새 터미널은 해당 그룹에 속하며, 활성 탭을 닫거나 옮기면 같은 그룹의 남은 탭을 선택한다<br>AC4: 그룹과 탭의 소속, 마지막으로 선택한 그룹을 프로젝트별로 저장하고 앱을 다시 열 때 복원한다<br>AC5: 그룹을 해제하면 소속 탭은 미분류로 옮겨지고 실행 중인 세션과 출력은 유지된다<br>AC6: 그룹 정보가 없는 이전 저장 파일은 기존 탭을 미분류로 유지하며 전체 보기로 연다<br>AC7: 탭을 다른 탭의 앞이나 뒤로 끌어 표시 순서를 바꾸고 프로젝트별로 저장·복원한다. 그룹 보기에서도 정렬할 수 있으며 탭 소속·선택·세션·출력은 유지한다. 드래그 위치를 표시하고 취소하거나 대상이 없어지면 기존 목록을 훼손하지 않는다<br>AC8: 사용자 그룹도 드래그로 앞뒤 순서를 바꾸고 저장·복원한다. 전체·미분류 필터는 맨 앞에 고정한다. 그룹 순서·이름을 바꿔도 선택한 그룹과 탭은 유지한다 | 초안 |
| TE-F03 | 터미널 작업 상태 표시 | 탭을 열지 않아도 작업 중인지, 완료 결과를 확인했는지 안다 | AC1: 세션 이름 왼쪽 점은 기본 상태에서 회색, 작업 중에는 주황색, 완료 후 미확인 상태에서는 초록색이다. Claude·Codex의 직접 입력과 작업 그래프 실행, 셸 명령에 적용하며 색상과 함께 상태 설명을 제공한다<br>AC2: 완료된 터미널이 실제로 화면에 보이고 앱 창이 활성화되어 있으면 확인 처리하여 기본 상태로 돌아간다. 다른 탭·다른 페이지·작업 그래프·비활성 창을 보는 동안에는 완료 표시를 유지한다. 늦게 도착한 확인 요청은 이후 작업의 상태를 바꾸지 않는다<br>AC3: 미확인 완료 상태는 저장하여 앱을 다시 열어도 유지한다. 종료로 중단된 작업 중 상태와 상태 정보가 없는 구버전 탭은 기본 상태로 복원한다 | 초안 |

## 규칙

- 세션 복원은 사용자가 선택한 프로젝트에만 적용한다.
- 대화 내용은 각 CLI가 관리한다. Orbit은 복원에 필요한 탭 상태와 세션 식별 정보를 저장한다.
- 앱 시작, 프로젝트 선택, CLI 재접속, 여러 줄 입력을 실제 사용 순서로 검증한다.
