## 규칙

- **DM-F02-AC17**: Print는 실행 입력·출력과 값 입력을 가지며 실행 시점의 텍스트·리스트·JSON·Bool·숫자를 출력 로그에 남기고 다음 노드로 진행한다. 에이전트 응답·셸 출력도 발생 순서대로 표시하고, Print 필터·복사·원본 노드 선택을 지원한다. 반복·함수의 출력은 실행별로 구분하며 선택하지 않은 분기는 출력하지 않는다. 로그는 그래프별 마지막 실행을 앱이 열려 있는 동안 유지한다.
- **DM-F02-AC18**: 구조화된 JSON의 기본 필드는 result이며 Field name·Type·Description과 String·Number·Boolean·Object·Array·Null을 영어로 표시한다. Array의 Items 타입과 Object의 Properties를 재귀적으로 정의·저장하고 응답의 중첩 타입·필수 필드·추가 필드를 검증한다. Properties가 비어 있으면 자유형 Object로 처리하고, 필드를 추가하면 지정한 구조를 엄격히 검사한다. 마지막 필드를 지우면 자유형으로 돌아가며 기존에 빈 Properties로 저장한 설정도 같은 규칙으로 실행한다. 기존 사용자 필드와 내부 제한이 없는 구조는 유지한다.
- **DM-F02-AC19**: 그래프 목록·속성 패널의 너비와 출력 로그 높이를 경계 드래그로 조절하고 저장한다. 다시 열어도 크기를 복원하며 캔버스 좌표·확대 비율·실행에는 영향을 주지 않는다. 최소·최대 크기, 더블클릭 초기화, 전체 초기화, 키보드 조절을 지원한다.
- **DM-F02-AC20**: 노드를 선택하면 Value 영역에서 데이터·계산 결과·에이전트·셸 응답을 바로 확인한다. JSON·Array의 Tree / Raw 전환과 복사를 지원하며 반복 실행의 값을 항목별로 선택한다. 실행 전 현재 값과 최근 응답으로 계산한 값을 구분하고, 대기·실패·건너뜀 상태를 값으로 대체하지 않는다. Print 추가나 터미널 열기는 필요하지 않다.

- `세션 불러오기` 목록은 Claude Code·Codex에 저장된 세션 이름을 우선 표시한다. 이름이 없을 때만 첫 메시지를 사용하며, 원본 세션 이름이나 대화 기록은 변경하지 않는다.
- 선택한 세션이 Orbit에서 이미 실행 중이면 같은 종류·세션 ID의 터미널 탭을 재사용한다. 탭 이름·출력·그룹을 유지하며, 실행 중인 탭이 없을 때만 새 탭을 연다. 같은 터미널을 다른 작업 노드가 사용 중이면 중복 전송하지 않고 해당 작업이 끝난 뒤 다시 실행하도록 안내한다.
- 기존 탭을 재사용할 때는 화면 출력이 멈추기를 기다리지 않고 프롬프트를 바로 보낸다. 새 탭은 입력 준비를 기다리며, 준비 중에도 다른 노드가 그 터미널에 중복 입력할 수 없다.
- Codex는 긴 입력의 붙여넣기를 확정한 뒤 전송해 마지막 Enter가 줄바꿈으로 소비되지 않게 한다. 일반 셸에서 실행한 Codex를 재사용할 때도 같은 방식으로 보낸다. 입력 내용과 내부 줄바꿈을 보존하고 전송은 한 번만 한다.
- 함수 변수 타입은 텍스트·텍스트 리스트·터미널·JSON·출력 구조·Bool·숫자다. 연결된 입력은 연결 값을 사용하고, 연결하지 않은 입력은 호출 노드에 적은 기본값을 사용한다. 리스트 기본값은 한 줄에 한 항목이며 Bool·숫자의 초기 기본값은 false·0이다.
- 함수 본체에 데이터를 놓거나 핀에서 새 함수를 만들면 타입이 맞는 입력을 찾는다. 화면을 축소해도 가장 가까운 출력 핀을 잡아 옆 변수와 혼동하지 않는다.
- 함수 Input은 내부로 인자를 내보내고, Output은 반환값을 받는다. 실행 선은 Input에서 시작해 Output으로 돌아와야 한다. 경계 노드는 삭제할 수 없고, 변수는 추가·삭제할 수 있다.
- 함수의 변수마다 이름과 별개인 고정 ID가 있어 이름을 바꿔도 선은 유지된다. 타입 불일치, 없는 변수, 중복 입력 연결, 빠진 반환값, 함수 순환 호출은 실행 전에 알린다.
- 함수는 중첩 호출할 수 있으며 각 호출의 인자와 반환값을 구분한다. 셸 출력을 반환받는 노드는 실행 선으로 그 함수 뒤에 있어야 한다.
- 예전 템플릿은 Input·Output을 덧붙여 읽는다. 기존 실행 흐름과 `{{입력}}`, 직접 입력 뒤에 연결 데이터를 붙이는 동작을 유지한다.
- For Each는 리스트를 받아 항목 순서대로 본문을 실행한다. 본문의 모든 갈래가 끝나야 다음 항목을 시작하며, 빈 리스트이거나 모든 항목을 마치면 완료 경로를 한 번 실행한다. 본문에서 실패하면 뒤의 반복과 완료 경로는 건너뛴다.
- 항목·0부터 시작하는 인덱스·본문 결과는 해당 반복 본문 안에서만 사용할 수 있다. 본문과 완료 경로는 겹칠 수 없으며, 본문 끝을 For Each에 다시 연결하지 않는다. 함수 안의 반복과 중첩 반복을 지원한다.

- If는 Bool 조건에 따라 참·거짓 중 한 실행 경로를 선택한다. 비교 노드는 같은 타입의 두 값을 비교하며 숫자에서는 같음·다름·크기 비교, 텍스트·Bool에서는 같음·다름을 지원한다. AND·OR·NOT은 Bool만 받아 Bool을 반환한다.
- Bool·숫자 노드는 상수 또는 텍스트·JSON에서 변환한 값을 출력한다. Bool 변환은 true·false만 허용하며 문자열의 존재 여부로 판정하지 않는다. 함수 변수·계산 입력의 타입 불일치와 중복 연결은 실행 전에 알린다.
- 선택하지 않은 경로는 조건 건너뜀으로 표시한다. 합류는 선택된 모든 앞 작업을 기다리며, 실행 실패는 다음 작업으로 전파한다. 반복문 안의 빈 분기는 다음 항목으로, 함수의 빈 분기는 Output으로 반환한다. 실행하지 않은 경로의 결과를 읽으면 오류로 알린다.

## 미결정 사항
