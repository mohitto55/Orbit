# Knowledge

## 역할

결정 사항, 용어, 컨벤션, 교훈 같은 프로젝트 지식을 쌓는다.

## 용어

이 도메인(바운디드 컨텍스트) 안에서의 뜻이다. 같은 단어도 다른 도메인에서는 뜻이 다를 수 있다.

| 용어 | 뜻 | 비고 |
|---|---|---|
| 지식 항목 | 도메인·명세·설계에 들어가지 않는 프로젝트 지식 하나 |  |
| 종류 | `결정` / `용어` / `컨벤션` / `교훈` / `주의` |  |
| 결정 (ADR) | 배경 / 결정 / 대안 / 결과로 쓴 지식 |  |
| 프로젝트 용어 | 도메인 경계를 넘어 프로젝트 전반에서 쓰는 용어 | 도메인 안에서만 유효한 용어는 각 `domain.md`의 용어 섹션에 둔다 |
| 근거 출처 | 지식이 나온 곳 (세션 발췌, 명세, 도메인, Task) |  |
| 하네스 포함 | 하네스에 넣을지 여부 |  |
| 대체 | 새 결정이 이전 결정을 폐기하고 연결되는 것 |  |

## 하지 않는 것

- 도메인·명세·설계의 원본 관리
