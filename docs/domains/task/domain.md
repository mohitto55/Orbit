# 할 일

> 해결 문제: P2

## 역할

나중에 할 일을 작업 유형과 시기를 붙여 보관하고, 때가 되면 다시 알려준다.

만든 Task는 나중에 고치거나 지울 수 있다. 고칠 수 있는 항목은 제목, 유형, 시기, 상태, 시작일, 종료일, 기한, 연결, 내용(마크다운)이다. 제목이 비어 있으면 저장할 수 없다. 고치거나 지운 직후에는 되돌리기로 되살릴 수 있다. 편집 창에서 상태를 `완료`로 바꿔 저장하면, 목록에서 바꿀 때처럼 도메인이 바뀌었는지 묻는다.

## 용어

이 도메인(바운디드 컨텍스트) 안에서의 뜻이다. 같은 단어도 다른 도메인에서는 뜻이 다를 수 있다.

| 용어 | 뜻 | 비고 |
|---|---|---|
| Inbox 항목 | 분류 전 할 일. 한 줄만 있어도 된다 |  |
| Task | 유형과 시기가 붙은 할 일 | 유형·시기 없이는 Task가 아니다. 만든 뒤에도 고치거나 지울 수 있다 |
| 유형 | `feature` / `bug` / `refactor` / `tech-debt` / `research` / `docs` / `test` / `spec-sync` / `design-sync` / `domain-sync` |  |
| 시기 (Horizon) | `지금` / `다음` / `나중` / `언젠가` |  |
| 기한 | 시기에 덧붙이는 날짜 | 시기 도래 알림은 기한만 본다 |
| 시작일 / 종료일 | Task에 붙이는 선택 날짜. 작업 기간을 나타낸다 | 종료일이 시작일보다 빠르면 저장할 수 없다. 기한과 별개이며 알림에 쓰지 않는다 |
| 타임라인 | 시작일부터 종료일까지를 가로 막대로 날짜 축 위에 보여주는 보기 | 둘 다 없는 Task는 나오지 않는다. 하나만 있으면 그 하루로 보인다 |
| 트리거 | 날짜 대신 조건으로 정한 시기 (명세 활성, 도메인 변경, 다른 Task 완료) |  |
| 재검토 | `나중`·`언젠가` Task를 주기적으로 다시 훑는 것 |  |
| 버림 | Task로 만들지 않고 닫은 Inbox 항목 |  |

## 하지 않는 것

- 작업 실행 자체
