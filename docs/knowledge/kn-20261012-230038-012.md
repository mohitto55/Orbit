결정 항목으로 남깁니다. WYSIWYG 편집기는 저장할 때 `{#s1}` 앵커, `[[위키링크]]`, HTML을 날릴 수 있습니다. 그래서 블록 하나씩 원문 마크다운으로 고치고, 손대지 않은 부분은 원문 그대로 둡니다. 블록으로 나눴다가 다시 합치면 원문과 같은지 테스트로 확인합니다. 도메인, 설계, 지식 페이지가 같은 편집기를 씁니다.

> "워드 같은 완전한 편집기로 만들지 않은 이유: 그런 편집기는 저장할 때 이 앱이 쓰는 `{#s1}` 앵커, `[[위키링크]]`, HTML 같은 특수 표기를 날려버리기 쉽습니다."
