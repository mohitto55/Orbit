# 테스트

> 해결 문제: P4

## 역할

수용 기준과 테스트 코드를 연결하고, 테스트를 실행해 결과를 요구사항 단위로 보여준다. (4층: 검증)

## 용어

이 도메인(바운디드 컨텍스트) 안에서의 뜻이다. 같은 단어도 다른 도메인에서는 뜻이 다를 수 있다.

| 용어 | 뜻 | 비고 |
|---|---|---|
| 테스트 연결 | 테스트 이름의 `[AC ID]`로 맺어진 AC–테스트 관계. 다대다 |  |
| 잘못된 연결 | 존재하지 않는 AC ID를 가리키는 테스트 |  |
| 실행 | 설정된 테스트 명령을 한 번 돌리는 것. 전체 또는 기능·도메인 단위 |  |
| 실행 결과 | 테스트별 통과 / 실패 / 건너뜀. JUnit XML에서 읽는다 |  |
| 검증 상태 | AC별 상태: `통과` / `실패` / `테스트 없음` / `미실행` / `확인 필요` | 연결된 테스트가 하나라도 실패하면 AC는 실패 |
| 확인 버전 | 테스트 연결마다 마지막으로 확인한 기능 명세 표 버전 |  |
| 검증률 | 통과한 AC 수 / 활성 AC 수 |  |

## 하지 않는 것

- 테스트 코드 작성, 결과 해석
