# 앱 기반 기능 명세

| ID | 기능 | 목적 | 수용 기준 | 상태 |
|---|---|---|---|---|
| PL-F01 | 화면 이동 | 화면 사이를 빠르게 오간다 | AC1: 사이드바에 화면마다 메뉴가 있다<br>AC2: 처리할 일이 있는 화면 메뉴에 개수 배지가 표시된다 | 초안 |
| PL-F02 | 알림 | 해야 할 때를 놓치지 않게 하되 귀찮게 하지 않는다 | AC1: 같은 종류의 알림은 하루에 한 번만 보낸다<br>AC2: Inbox 정리 알림은 설정한 시각 이후에만 보낸다 | 초안 |
| PL-F03 | 빠른 기록 단축키 | 어디서든 떠오른 할 일을 바로 적는다 | AC1: 앱이 뒤에 있어도 단축키로 빠른 기록 창이 열린다<br>AC2: Enter로 저장하고 Esc로 닫는다 | 초안 |
| PL-F04 | 자동 업데이트 | 새 버전을 따로 찾지 않아도 된다 | AC1: 설치판은 시작할 때 GitHub Releases에서 새 버전을 확인하고 내려받는다<br>AC2: 업데이트 확인에 실패해도 앱은 계속 동작한다<br>AC3: 사이드바에 지금 버전이 보이고, 새 버전이 있으면 배지로 알린다. 업데이트 창에서 상태(확인 중·받는 중 %·설치 준비됨·최신·실패)를 보고 지금 확인 / 내려받기 / 재시작해서 설치를 할 수 있다<br>AC4: 자동 확인(시작 시·6시간마다)과 자동 내려받기를 켜고 끌 수 있다 | 초안 |
