# 터미널 기능 명세

하위 도메인의 규칙을 조정해 이루는 사용자 기능과 수용 기준. 기능마다 쓰는 규칙을 참조한다.

| ID | 기능 | 목적 | 수용 기준 | 상태 |
|---|---|---|---|---|
| DM-F01 | 기본 터미널 오픈 |  |  | 초안 |
| DM-F02 | 터미널 그래프 | 에이전트·셸 작업과 그 입력 데이터를 노드로 이어, 여러 단계의 작업을 한 그래프로 실행한다 | AC1: 노드는 두 종류다 (언리얼 블루프린트 방식). 액션 노드는 맡은 작업을 수행하고, 데이터 노드는 값을 담는다<br>AC2: 데이터 노드는 값의 모양에 따라 단일과 리스트 두 종류다<br>AC3: 노드 사이의 선은 베지어 곡선으로 그린다<br>AC4: Claude Code·Codex 노드는 `세션 불러오기`로 이 프로젝트의 로컬 세션을 골라 그 대화를 이어서 쓸 수 있다<br>AC5: 액션 노드는 실행 입력 핀으로 실행 신호를 받으면 작업을 시작하고, 작업이 끝나면 실행 출력 핀에 연결된 다음 노드로 실행을 넘긴다<br>AC6: 액션 노드는 실행될 때 데이터 입력 핀에 연결된 데이터 노드의 값을 받아 작업에 쓴다<br>AC7: 데이터 출력 핀이 있는 액션 노드는 작업 결과를 그 핀에 연결된 데이터 노드로 내보낸다 (데이터 출력 핀 유무는 노드 종류마다 다르다)<br>AC8: 데이터 출력 핀에서 선을 끌어 빈 공간에 놓으면, 그 핀의 값을 담은 데이터 노드가 새로 생기고 핀과 연결된다<br>AC9: 모든 노드는 uuid로 구분하며, uuid는 화면에 표시하지 않는다<br>AC10: 새 노드의 이름은 노드 종류 이름(예: `텍스트`)이며, 사용자가 언제든 바꿀 수 있다<br>AC11: 한 그래프 안에서 노드 이름은 겹치지 않는다. 생성이나 이름 변경으로 겹치면 뒤에 1부터 늘어나는 숫자를 붙인다 (`텍스트` → `텍스트 1` → `텍스트 2`) | 초안 |
